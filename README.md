# sdet-showcase

A portfolio project for SDET work: end-to-end and API test automation written in strict TypeScript.

> Status: work in progress (week 1 of 12).

## Goals

- Playwright E2E tests against a locally running RealWorld app
- A typed API layer with schema validation
- CI with sharding and flaky-test tracking
- Clear documentation written in English

## Requirements

- Node.js 22 or newer
- pnpm 12

## Getting started

```bash
pnpm install
pnpm typecheck
```

## Project structure

```
algo/    algorithm practice solutions
docs/    setup notes and design decisions
src/     shared test utilities
tests/   Playwright tests (added in week 1)
```
